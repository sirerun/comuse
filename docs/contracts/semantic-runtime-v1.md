internal/backend owns leaf DTOs; root public package aliases them. No cycles.

Capabilities {Accessibility bool, Input bool, ScreenCapture bool, QualifiedInput bool, Reasons []string}; Doctor {Capabilities Capabilities, Permissions map[string]string}; Window {Ref string, Process ProcessIdentity, Title string}; Element {Ref,ParentRef string, Order int, Role,Label string, Value *string, Enabled *bool, Actions []string, Classification string}; Coverage {Complete bool, Reason string}; Snapshot {WindowRef string, StateID string, ObservedAt time.Time, Elements []Element, Coverage Coverage}; ElementContent {WindowRef,ElementRef,StateID string, Text string}; Action {ID,WindowRef,ElementRef,StateID,Kind,Text string}; ActionResult {ActionID,Execution,Verification,StateStatus,Cleanup string}; States explicitly not_applied/applied/partial/unknown, verified/unverified, unchanged/changed/unknown, complete/dirty/unknown.
Backend interface: Doctor(context.Context)(Doctor,error); Windows(context.Context,Budget)([]Window,error); Observe(context.Context,string,Budget)(Snapshot,error); ReadElement(context.Context,string,string,string,Budget)(ElementContent,error); Execute(context.Context,Action)(ActionResult,error); Close(context.Context)error. Implemented backend must bound work and freshly classify targets; raw classifications never trusted as admission by core alone.
Root Config {Backend Backend; Scope Scope; Budget Budget; AllowValues bool; ApprovalProvider ApprovalProvider; WriterDirectory string; WriterKey []byte; MaxActions int}; NewSession(Config)(*Session,error). Session methods Doctor(ctx), State(ctx) same Doctor status, Windows(ctx), Observe(ctx,windowRef), ReadElement(ctx,windowRef,elementRef,stateID), Do(ctx,Action), Wait(ctx,windowRef,timeout) fresh bounded observe, Close(ctx). Backend ownership transferred to session only after successful construction. Constructor does no native calls; Close retains ownership if backend fails to close.
ApprovalProvider interface Approve(context.Context,ApprovalRequest)(Approval,error), only trusted host API not JSON; ApprovalRequest includes SessionID,Action,Process,ObservedAt,PolicyVersion,ExpiresAt; Approval repeats those binding fields and expires in <=2m. Approvals exact-bound/single-use, fail closed. Do validates fresh observation/state and per-target advertised capability; native qualifiedinput false blocks dispatch. Durably records action intent before approved dispatch, caches terminal metadata without text, no redispatch unknown response. Copy immutable config, share lifetime quotas, safe errors.
Observation core filters secure/unknown classifications and values opt-in before canonical stateID; unsupported classifications treated conservatively. Identity checks and bounded serialized output at core. StateID computed only over filtered semantic state, deterministic no timestamp/hiddenvalues leaks. Core normalizes native stateID to its public StateID; preserve private mapping for native Execute/ReadElement revalidation. No fabricated input enablement.
CLI cmd/comuse reads trusted --config file with library_path/scope/budget/allow_values only; no approval keys or auto approval. Supports doctor/state/windows/a11y/read-element/wait/mcp, JSON input one bounded object and unknown-field rejection. Exits RFC 0/1/2/3/4, stdout shared envelope {schema_version:1,status:ok|error,result?,error?}. No images or writes advertised.

Official SDK pinned existing; tools computer_state,computer_windows,computer_a11y,computer_read_element,computer_wait; same strict core, no approval issuance/raw native requests. Real SDK protocol tests. Capability-dependent action registration only after qualified and admission path proven; current source default readonly.

Native ARM macOS/cgo build, other platforms typed unsupported. Native main owner must actually be process main (not arbitrary locked thread). Production native dylib ComuseMacOS under native/macos.
