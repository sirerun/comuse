Production contract v1 (source preparation, not runtime admission):
internal/backend owns leaf DTOs; root public package aliases them. No cycles.
ProcessIdentity {PID int32, BundleID string, LaunchID string}; Scope {Processes []ProcessIdentity, ExpiresAt time.Time}; Budget {MaxDepth,MaxNodes,MaxBytes int, Timeout time.Duration}; Config native {Scope Scope, LibraryPath string, AllowValues bool}; typed Error {Code string, Message string}; exported ErrorCode helper uses errors.As, no native payload in error.
Capabilities {Accessibility bool, Input bool, ScreenCapture bool, QualifiedInput bool, Reasons []string}; Doctor {Capabilities Capabilities, Permissions map[string]string}; Window {Ref string, Process ProcessIdentity, Title string}; Element {Ref,ParentRef string, Order int, Role,Label string, Value *string, Enabled *bool, Actions []string, Classification string}; Coverage {Complete bool, Reason string}; Snapshot {WindowRef string, StateID string, ObservedAt time.Time, Elements []Element, Coverage Coverage}; ElementContent {WindowRef,ElementRef,StateID string, Text string}; Action {ID,WindowRef,ElementRef,StateID,Kind,Text string}; ActionResult {ActionID string; Execution ExecutionStatus; Verification {Status VerificationStatus, Reason string}; StateStatus StateStatus; Cleanup CleanupStatus}. Execution is not_applied/applied/partially_applied/unknown; Verification.Status is verified/failed/unavailable; StateStatus is available/unavailable; Cleanup is complete/dirty/unknown. These are typed closed enums aligned to RFC section 5.3.
Backend interface: Doctor(context.Context)(Doctor,error); Windows(context.Context,Budget)([]Window,error); Observe(context.Context,string,Budget)(Snapshot,error); ReadElement(context.Context,string,string,string,Budget)(ElementContent,error); Execute(context.Context,Action)(ActionResult,error); Close(context.Context)error. Implemented backend must bound work and freshly classify targets; raw classifications never trusted as admission by core alone.
Root Config {Backend Backend; Scope Scope; Budget Budget; AllowValues bool; ApprovalProvider ApprovalProvider; WriterDirectory string; WriterKey []byte; MaxActions int}; NewSession(Config)(*Session,error). Session methods Doctor(ctx), State(ctx) same Doctor status, Windows(ctx), Observe(ctx,windowRef), ReadElement(ctx,windowRef,elementRef,stateID), Do(ctx,Action), Wait(ctx,windowRef,timeout) fresh bounded observe, Close(ctx). Backend ownership transferred to session only after successful construction. Constructor does no native calls; Close retains ownership if backend fails to close.
ApprovalProvider interface Approve(context.Context,ApprovalRequest)(Approval,error), only trusted host API not JSON; ApprovalRequest includes SessionID,Action,Process,ObservedAt,PolicyVersion,ExpiresAt; Approval repeats those binding fields and expires in <=2m. Approvals exact-bound/single-use, fail closed. Do validates fresh observation/state and per-target advertised capability; native qualifiedinput false blocks dispatch. Durably records action intent before approved dispatch, caches terminal metadata without text, no redispatch unknown response. Copy immutable config, share lifetime quotas, safe errors.
Observation core filters secure/unknown classifications and values opt-in before canonical stateID; unsupported classifications treated conservatively. Identity checks and bounded serialized output at core. StateID computed only over filtered semantic state, deterministic no timestamp/hiddenvalues leaks. Core normalizes native stateID to its public StateID; preserve private mapping for native Execute/ReadElement revalidation. No fabricated input enablement.
CLI cmd/comuse reads trusted --config file with library_path/scope/budget/allow_values only; no approval keys or auto approval. Supports doctor/state/windows/a11y/read-element/wait/serve/mcp. The serve command accepts bounded newline-delimited command objects and emits one envelope per command, preserving refs/baselines within the same Session; references do not survive process exit, JSON input one bounded object and unknown-field rejection. Exits RFC 0/1/2/3/4, stdout shared envelope {schema_version:1,status:ok|error,result?,error?}. No images or writes advertised.
MCP package mcp: NewServer(*comuse.Session)*sdk.Server, Serve(ctx,*Session,io.ReadWriteCloser)error. Official SDK pinned existing; tools computer_state,computer_windows,computer_a11y,computer_read_element,computer_wait; same strict core, no approval issuance/raw native requests. Real SDK protocol tests. Capability-dependent action registration only after qualified and admission path proven; current source default readonly.
Native package darwin: Config is backend.Config. Run(ctx,Config,func(backend.Backend)error)error owns native open/pump/close on process-main while user callback runs worker, cancellation drains. Native ARM macOS/cgo build, other platforms typed unsupported. Native main owner must actually be process main (not arbitrary locked thread). Production native dylib ComuseMacOS under native/macos. Scoped already-running apps only, launchID native fresh derived start-time. AX readonly observation actual; input implemented but compile closed pending qualification; no fixture-specific hardcoded app in production path.

Frozen source-phase actions: press, replace, insert. Press requires empty Text; replace permits empty UTF-8 Text to clear the field; insert requires nonempty UTF-8 Text; both are bounded to <=8192 bytes. Unsupported kinds fail unsupported. IDs and references are opaque ASCII nonempty bounded <=128 bytes; maximum retained snapshot generations is 8 per window and total snapshot storage 4MiB with 2-minute TTL. Observe canonicalizes sorted element refs with parent/order/role/label/allowed value/enabled/sorted deduplicated actions plus window ref and coverage. Timestamps and native state IDs never enter the public state hash. Secure/unknown elements are omitted before canonicalization; filtered descendants may not reference omitted parents. Label/title free text remains scoped observation content, not diagnostic metadata. Private native StateID mapping is retained only alongside its filtered public state, never serialized. Native state changes from hidden values must not affect public state identifiers.
Errors frozen: invalid_request, policy_refused, approval_required, element_stale, state_expired, permission_denied, unsupported, backend_unavailable, desktop_busy, rate_limited, budget_exceeded, cancelled, session_closed, unknown_outcome, internal_error. All free-form backend messages are replaced with stable safe messages at public adapter/core boundaries. Detailed result payload is metadata only; no text in action journal/errors. Root shared envelope is a source-phase wrapper and does not claim the complete RFC release envelope (usage/duration/compact state are not yet qualified); all adapters must share it, and release parity remains an explicit remaining task before full public acceptance.

Native factory bootstrap clarification: only initial native Open may bind an empty LaunchID for an explicitly host-configured PID+BundleID to native process start time. A supplied LaunchID must match. darwin.ResolvedScope(backend.Backend)(Scope,error) returns a deep copy of that exact fully bound scope after successful Open. NewSession requires those nonempty bound LaunchIDs and makes no backend calls. No operation rebinds a scope to a new process generation. AllowValues is an explicit host native config flag default false, passed consistently to Session; metadata-only native observation must not read/hash values. Session stores original native Snapshot.StateID privately and substitutes it into backend ReadElement/Execute; no public/native binding hook or native ID serialization.
